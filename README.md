# kLib
Did you know creating software leads to writing utility classes?
And these classes prove themselves essential? Over and over again?

This is it - a desperate attempt to keep track of the latest version of these *SUPER* **MEGA** ***TURBO*** useful modules that I use in every C++ solution.

Some of them have a long history, while others have been used... twice. However, they share one common property: usefulness.

## Usage
1. Copy and paste the desired modules (along with headers).
2. C++20 compiler required.
